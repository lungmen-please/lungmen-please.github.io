# 龙门，请出示证件 · LUNGMEN, PLEASE

《明日方舟》同人小游戏，Papers, Please 式的检查站玩法。
**基于 [IP, PLEASE · 请出示你的 IP](https://ip-please.github.io) 修改。** 在线玩：<https://chenziqiadam.github.io/lungmen-please/>（需在仓库 Settings → Pages 开启）。 本作是粉丝同人作品，与鹰角网络无关。

切尔诺伯格出事前后，你在龙门边境检查站当审查员。工作只有一项：核对证件，决定谁能进入龙门。
证件上写着种族，旅客头上长着耳朵、角、光环，身后拖着尾巴。它们得对得上。

## 玩法

叫号 → 旅客递上证件 → 对照规则手册核对 → 盖【批准】或【拒绝】章（或者【拘留】）。

- **检查**：打开检查模式，依次点两处信息（比如“证件种族”和“旅客本人”、“有效期”和“今天日期”），找出矛盾，再【质询】旅客。
- **请摘帽**：帽子、兜帽会挡住耳朵和角，看不清就请旅客摘下来。
- **源石探测**（第 3 天起）：看到旅客身上的源石结晶、私藏的源石和整合运动的面具。
- 每处理对一位旅客挣 5 龙门币；先用【检查】查出矛盾再拒绝或拘留，多拿 2 龙门币查证奖金。每天前两次出错只是警告，之后每次罚款。
- 下班后要付房租、买食物，还有……小雅的抑制剂。不买食物，第二天会迟到；抑制剂断一次病情加重，断第二次小雅就会被带走。

- **档案**：标题页的【档案】记录解锁过的结局、成就和见过的熟面孔，通关后不会清空。
- **快捷键**（桌面端）：空格 叫号，1 批准，2 拒绝，3 拘留，E 检查，R 源石探测，F 手册，H 请摘帽，Q 质询。

### 种族图鉴（游戏里手册第 2 页有图）

| 种族 | 特征 |
|---|---|
| 菲林 | 三角猫耳，细长尾巴 |
| 卡特斯 | 长兔耳，看不到尾巴 |
| 佩洛 | 两侧下垂的犬耳，短尾巴 |
| 鲁珀 | 大而尖的狼耳，蓬松的中等尾巴 |
| 沃尔珀 | 特大狐耳，巨大狐尾、尾尖白色 |
| 乌萨斯 | 头顶一对圆熊耳，没有尾巴 |
| 札拉克 | 带一撮毛的小尖耳，向上卷的大尾巴 |
| 萨卡兹 | 深色后弯的角，尖耳朵 |
| 瓦伊凡 | 浅色直角，人类的圆耳朵，粗壮鳞尾 |
| 萨科塔 | 头顶光环，背后小翅膀 |
| 黎博利 | 头部两侧长羽毛，没有兽耳 |

头饰（比如猫耳发箍）不算种族特征。

### 五天

| 天 | 新规则 / 新工具 |
|---|---|
| 1 | 上午只核对种族，陈督察带你上手；星熊来过之后，加查照片、有效期和入境许可 |
| 2 | 体检报告；感染者禁止入境 |
| 3 | 萨卡兹须持担保函；源石探测仪；拘留走私者 |
| 4 | 整合运动成员予以拘留；持罗德岛干员证的感染者可以入境 |
| 5 | 乌萨斯籍旅客一律禁止入境 |

你的选择、家人的处境和一张来历不明的纸条，会把你带向不同的结局。

### 彩蛋

剧情角色每天都会出场，但排在第几位每次略有不同。龙门篇的熟面孔偶尔会排到你的窗口前（第 2 天起每天至少一位），也会从检查站外的马路上路过。
他们未必都按常理出牌——放行还是拒绝，有时会上第二天的报纸。标题页、日期栏和桌面上也藏着一些小东西。

## 本地运行

纯静态网页，不加载任何外部资源。在仓库根目录运行：

```bash
python -m http.server
```

然后打开 <http://localhost:8000>。直接双击 `index.html` 也能玩。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` / `style.css` | 页面与样式 |
| `data.js` | 种族、国家、规则、报纸、台词 |
| `art.js` | 像素立绘（逐像素画耳朵、尾巴、角、光环）和源石探测视图 |
| `sfx.js` | 音效（WebAudio 现场合成） |
| `gen.js` | 旅客生成、剧情角色、矛盾判定 |
| `game.js` | 界面、流程、主循环 |
| `eggs.js` / `eggs.css` | 彩蛋（剧透预警） |
| `px.woff2` / `px.ttf` | 像素字体子集（网页优先加载 woff2，ttf 是后备） |
| `favicon.png` / `og.png` | 网站图标和分享预览图，由 `tools/make_share_images.py` 生成 |
| `tools/sim_test.js` | 旅客模拟测试：`node tools/sim_test.js`，检查没有“无解旅客”、剧情角色都会出场 |
| `tools/art-variants/` | 另外两套备选立绘画风（动漫半身 / 3/4 侧身），覆盖 `art.js` 即可换画风 |
| `tools/subset_font.py` | 重新生成字体子集（源字体在 `tools/fonts/`） |

## 重新生成字体

改了游戏里的文字、用到新汉字后，重新裁一次字体：

```bash
pip install fonttools brotli
python tools/subset_font.py
```

完整字体在 `tools/fonts/`（来自 [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)，12px、zh_hans）。脚本会扫描仓库里所有 `.js` / `.html` / `.css` 里出现的字符。
